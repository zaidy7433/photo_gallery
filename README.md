## 🌟 About The Project

**Photo Gallery** is a visually appealing website designed to showcase beautiful photographs in an organized and interactive layout.

Built using fundamental front-end technologies, this project focuses on clean design, smooth interactions, and an enjoyable browsing experience across different screen sizes.

## ✨ Features

* 🖼️ **Beautiful Image Gallery** — Display photographs in an attractive layout.
* 📱 **Responsive Design** — Adapt the layout to different screen sizes.
* 🎨 **Modern UI** — Enjoy a clean and visually appealing interface.
* 🔍 **Hover Effects** — Add interactive effects when hovering over images.
* ⚡ **Smooth Animations** — Enhance the browsing experience.
* 🧩 **Organized Layout** — Keep images arranged neatly.
* 💻 **Beginner-Friendly Code** — Easy to understand and customize.

## 🛠️ Technologies Used

| Technology    | Purpose                          |
| ------------- | -------------------------------- |
| HTML5         | Website structure                |
| CSS3          | Styling, layouts, and animations |
| JavaScript    | Interactive functionality        |
| CSS Grid      | Image arrangement                |
| Media Queries | Responsive layouts               |
| GitHub Pages  | Website hosting                  |

## 💻 Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/zaidy7433/photo_gallery.git
```

**2. Open the project folder**

```bash
cd photo_gallery
```

**3. Run the website**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
